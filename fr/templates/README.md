# Modèles

[↑ Documentation](../README.md)

Des documents prêts à copier **hors de ce dépôt** et à remplir pendant ou après un incident.
Un modèle rempli contient des informations sensibles : il ne doit jamais être publié.

| ID | Modèle | Quand l'utiliser |
|---|---|---|
| T01 | [Rapport d'incident](T01-rapport-d-incident.md) | Dès l'ouverture de l'incident, rempli au fil de l'eau |
| T02 | [Post-mortem](T02-post-mortem.md) | Après la clôture, pour le retour d'expérience (sans recherche de coupable) |
| T03 | [Communication de crise](T03-communication-de-crise.md) | Messages types : salariés, clients, personnes concernées (RGPD), presse |
| T04 | [Registre de preuves](T04-registre-de-preuves.md) | Dès la première collecte de preuve (chaîne de custody) |
