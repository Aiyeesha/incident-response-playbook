# Templates

[↑ Documentation](../README.md)

Documents ready to copy **outside this repository** and fill in during or after an incident.
A completed template contains sensitive information: it must never be published.

| ID | Template | When to use it |
|---|---|---|
| T01 | [Incident report](T01-incident-report.md) | From the moment the incident is opened, filled in as you go |
| T02 | [Post-mortem](T02-post-mortem.md) | After closure, for lessons learned (blameless) |
| T03 | [Crisis communication](T03-crisis-communication.md) | Message templates: employees, customers, data subjects (GDPR), press |
| T04 | [Evidence log](T04-evidence-log.md) | From the first piece of evidence collected (chain of custody) |
